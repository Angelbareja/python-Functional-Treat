# 📊 Data Analyzer & Transformer

A beginner-friendly Python project that allows users to input numerical data and perform various analysis and transformation operations using an interactive menu-driven program.

## 🚀 Features

- Input custom dataset (1D array)
- Display data summary
- Calculate factorial of a number
- Filter data using threshold values
- Sort data in ascending or descending order
- Display statistical analysis of dataset
- Interactive menu-based interface

## 🛠 Technologies Used

- Python 3
- Lists
- Functions
- Recursion
- Lambda functions
- Built-in methods (`min()`, `max()`, `sum()`, `sort()`)

## ⚡ How It Works

### Main Menu Options:

1. **Input Data**
   Users can enter multiple integer values.

2. **Display Data Summary**
   Shows:

   * Total elements
   * Minimum value
   * Maximum value
   * Sum of values
   * Average value

3. **Calculate Factorial**
   Uses recursion to calculate factorial.

4. **Filter Data by Threshold**
   Displays numbers greater than the entered threshold.

5. **Sort Data**
   Sorting options:

   * Ascending
   * Descending

6. **Display Dataset Statistics**
   Shows complete statistical summary.

7. **Exit Program**
